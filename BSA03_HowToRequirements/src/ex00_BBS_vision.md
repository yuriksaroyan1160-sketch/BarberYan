# Концепция системы «BarberYan»

## 1. Введение

### 1.1. Для кого предназначен документ
Настоящий документ предназначен для руководства сети барбершопов (заказчика), команды разработки, а также для всех заинтересованных сторон, участвующих в создании и внедрении системы. Документ описывает высокоуровневое видение продукта, его цели и границы.

### 1.2. Цель и область применения
Цель документа — зафиксировать бизнес-требования к системе онлайн-записи, определить её границы, ключевые проблемы, которые она решает, и основные бизнес-цели.
<br>Область применения: проектирование и разработка веб-сервиса для сети барбершопов.

## 3. Бизнес-требования

### 3.1. Проблемы, для решения которых создается система
В текущем процессе (as is) выявлены следующие ключевые проблемы:
1.  **Ограниченный поток клиентов** у руководителя сети из-за отсутствия современного способа записи.
2.  **Высокие трудозатраты менеджеров:** постоянные звонки для записи, ручная отправка напоминаний клиентам.
3.  **Неудобство для клиентов:** сложно дозвониться, чтобы записаться; непонятно, в какое время свободен мастер; клиенты забывают о записи без напоминаний.
4.  **Риски штрафов:** сложно контролировать ведение журнала санитарной обработки.

### 3.2. Предусловия, окружение, ситуация
Сеть барбершопов имеет несколько филиалов, в каждом работают мастера и менеджеры. Оплата принимается на месте, данные для бухгалтерии передаются вручную. У компании есть потребность в масштабировании и выходе на новый уровень сервиса.

### 3.3. Возможности, позволяющие решить проблемы с помощью нашей системы
*   Внедрение **веб-сервиса с круглосуточной онлайн-записью** (как для зарегистрированных, так и для незарегистрированных посетителей).
*   **Автоматическая отправка напоминаний** клиентам через выбранный канал связи (Telegram, WhatsApp, VK, СМС).
*   **Наглядный календарь слотов** для клиентов и мастеров.
*   **Электронный журнал санобработок** с уведомлениями для менеджеров.
*   **Автоматизация отчётности** и сбора отзывов.

### 3.4. Бизнес-цель(-и)
1.  Расширить клиентскую базу за счёт внедрения удобного онлайн-сервиса записи.
2.  Снизить трудозатраты сотрудников (менеджеров) за счёт автоматизации рутинных процессов (напоминания, запись).
3.  Повысить средний чек и удержание клиентов за счёт качественного сервиса и системы отзывов.
4.  Исключить штрафы за счёт строгого контроля санитарных норм.


## 4. Границы проекта

### Основные роли системы и их функции:
1.  **Клиент (зарегистрированный / незарегистрированный):**
    *   Просмотр каталога услуг и свободных слотов.
    *   Бронирование, перенос или отмена записи.
    *   Получение уведомлений (напоминаний).
    *   Просмотр истории своих записей (для ЛК).
    *   Оставление отзывов и оценок.
2.  **Мастер:**
    *   Просмотр своего расписания и записей клиентов.
    *   Просмотр отзывов о своей работе.
3.  **Менеджер:**
    *   Управление расписанием мастеров и перечнем услуг.
    *   Отметка о выполнении услуги.
    *   Внесение данных об оплате.
    *   Контроль санитарных обработок (журнал).
    *   Просмотр отчётов и отзывов.
4.  **Администратор:**
    *   Управление правами доступа пользователей в системе.
5.  **Внешние системы (по потокам данных):**
    *   Бухгалтерия (получение данных об оплатах).
    *   Санэпиднадзор (получение отчётности).
