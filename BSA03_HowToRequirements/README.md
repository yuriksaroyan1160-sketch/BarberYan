# BSA03_HowToRequirements — Концепция (Vision)

## Exercise 00 — Vision (Концепция)

[src/ex00_BBS_vision.md](./src/ex00_BBS_vision.md)

Документ «Концепция» (Vision) — это отправная точка для любого проекта. Он 
описывает, для кого создается система, какие бизнес-проблемы она решает и 
каковы её границы. В отличие от детальных требований, Vision дает 
высокоуровневое понимание продукта и помогает всем стейкхолдерам 
договориться об общем видении до начала разработки.

В этом документе зафиксированы бизнес-цели, проблемы текущего процесса 
(as is) и возможности системы (to be), а также основные роли и их функции.

## Связь с другими блоками

Vision опирается на информацию из BSA00–BSA02 (источники, стейкхолдеры, 
модели as is / to be). В свою очередь, он служит основой для всех 
последующих проектов: доменной модели (BSA04), BPMN (BSA06) и Use Cases 
(BSA08), где требования из Vision начинают детализироваться.
