| Вопросы | Ответы |
|:---|:---|
| За какое время до оказания услуги клиент может забронировать слот? | За 2 часа до оказания услуги |
| За какое время до оказания услуги, клиент может отменить запись? | За 2 часа до оказания услуги |
| Накладывается ли штраф на клиента, если запись отменена позже этого времени? | Менеджер связывается с клиентами, подтверждает записи и ставит соответствующие отметки |
| Может ли клиент сам отменить запись через сайт? | Да, может |
| Какие данные должен заполнить клиент чтобы забронировать слот? | Канал связи. В случае если пользователь регистрируется то оставляет номер, почту и ФИ |
| Как система блокирует слот для избежания двойного бронирования? | Система дважды проверяет статус бронирования слота: при нажатии на слот и при нажатии на кнопку записаться (после заполнения данных) |
