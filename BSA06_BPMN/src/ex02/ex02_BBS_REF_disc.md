**Управление справочниками (мастера, услуги)**

- REF (Reference Data)

- Определить и согласовать правила ведения справочников мастеров и
  услуг, включая процедуры добавления, изменения, архивации данных при
  увольнении сотрудников, обработку активных записей, а также уточнить
  обязательные атрибуты и связи между сущностями для обеспечения
  корректной работы системы записи.

- 03.09.2026

- Менеджер

| Вопрос | Ответ |
|:---|:---|
| Какие есть справочники | Мастера, Услуги |
| Кто управляет справочниками | Менеджер |
| Что делать если мастер увольняется, а у него есть активные записи | Если мастер уволился, менеджер удаляет или заносит в архив Мастера из справочника, проверяет есть ли у мастера активные записи. Если есть, находит данные клиента, и отправляет уведомление, с предложением, заменить мастера |
| Нужен ли архив для справочников | Нужен, так как работодатель должен хранить информацию о сотрудниках по № 125-ФЗ «Об архивном деле в РФ» |
| Как часто менеджер обновляет справочники | При появлении нового сотрудника или услуги |
| Какие поля обязательны для создания услуги | Название, длительность, цена |
| Какие поля обязательны для создания мастера | ФИО, должность, стаж, рейтинг, номер телефона |
| Какая связь между мастером и услугой | Многие ко многим |
