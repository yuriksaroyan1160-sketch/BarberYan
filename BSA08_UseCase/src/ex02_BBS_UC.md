| Идентификатор UC | UC-CLT-01 |
|:---|:---|
| Название UC | Выбор услуги и бронирование слотов |
| Цель UC | Обеспечить клиентам возможность выбирать услуги мастера и бронировать слоты |
| Основное действующее лицо | Клиент |
| Роль действующего лица и его интерес | Потребитель услуги<br>Иметь возможность выбрать услугу, мастера и забронировать слот |

| - Менеджер | Хочет видеть актуальную загрузку мастеров и избегать накладок |
| - Мастер | Хочет видеть в своем расписании все забронированные слоты |
| Предусловие | 1. Клиент должен зайти на сайт<br>2. В справочниках должны присутствовать все услуги и мастера<br>3. Расписание каждого мастера должно быть настроено |
| Триггер | У клиента появилась нужда в косметологических или парикмахерских услугах |
| Постусловия | |
| - Минимальные гарантии | Данные о записи не повреждены |
| - Гарантии успеха | Клиент успешно записался на желаемое время. Слот забронирован |
