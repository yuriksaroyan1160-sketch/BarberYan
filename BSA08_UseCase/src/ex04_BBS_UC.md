| Идентификатор UC | UC-MSR-01 |
|:---|:---|
| Название UC | Посмотреть расписание забронированных услуг |
| Цель UC | Обеспечить мастеру доступ к актуальному расписанию, чтобы мастер мог планировать рабочее время |
| Основное действующее лицо | Мастер |
| Роль действующего лица и его интерес | Специалист оказывающий услугу<br>Хочет видеть своё расписание и понимать, к какому времени<br>и на какую услугу записан клиент |
| Другие заинтересованные стороны и их интересы: | |
| - Менеджер | Хочет, чтобы мастер был в курсе своих записей и не возникало накладок |
| - Клиент | Хочет, чтобы мастер знал о его записи и оказал услугу вовремя |
| Предусловие | 1. Мастер авторизован в системе<br>2. Расписание мастера настроено<br>3. Существует хотя бы одна забронированная запись |
| Триггер | Мастеру необходимо ознакомиться со своим расписанием |
| Постусловия | |
| - Минимальные гарантии | Данные о записях не повреждены |
| - Гарантии успеха | Мастер получил актуальную информацию о забронированных услугах |
