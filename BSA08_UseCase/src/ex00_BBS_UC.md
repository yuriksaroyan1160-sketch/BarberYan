| Идентификатор UC | UC-SCH-01 |
|:---|:---|
| Название UC | Настроить расписание услуг мастеров |
| Цель UC | Обеспечить актуальность расписания услуг мастеров, чтобы клиенты могли записываться |
| Основное действующее лицо | Менеджер |
| Роль действующего лица и его интерес | Управляющий расписанием.<br><br>Иметь возможность быстро редактировать расписание каждого мастера через систему, чтобы избежать ошибок |
| Другие заинтересованные стороны и их интересы: | |
| - Мастер | Хочет видеть точное расписание своих рабочих дней и услуг, чтобы не возникало путаницы в графике и не приходилось уточнять его у менеджера |
| - Клиент | Видеть, какие услуги и в какие дни оказывает мастер, чтобы понимать, когда он может обратиться |
| Предусловие | 1. Менеджер должен войти в свой личный кабинет<br><br>2. В справочниках должны быть все мастера и оказываемые каждым мастером услуги<br><br>3. Менеджер должен иметь информацию о рабочей неделе каждого мастера |
| Триггер | Менеджер получает уведомление от мастера о том, что нужно внести изменения в расписании |
| Постусловия | |
| - Минимальные гарантии | Изменения либо применены полностью, либо вовсе не применены |
| - Гарантии успеха | В разделе с расписанием есть ФИО мастера и его актуальное расписание<br><br>Данные в системе изменились и верны |
