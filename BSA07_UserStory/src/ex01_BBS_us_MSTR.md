## US #1

| Заголовок | Описание |
|---|---|
| Идентификатор US | US-MSTR-01 |
| Заголовок US | Просматривать записи на услуги |
| Формулировка | Как мастер, я хочу видеть все записи на мои услуги, чтобы самостоятельно организовать своё рабочее время. |
| Роль пользователя | Мастер |
| Польза (ценность) для роли | Самостоятельно организовать свой рабочий день |
| Требуемые действия | Открыть расписание и посмотреть все забронированные записи |
| **Критерии приёмки** | |
| Предусловие | Мастер зашёл на сайт под своей учётной записью |
| Действия пользователя в системе | 1. Зайти в раздел «Расписание»<br>2. Посмотреть все забронированные слоты |
| Результат (ценность для пользователя) | Понимать, сколько клиентов будет за день и в какое время |

## US #2

| Заголовок | Описание |

| Идентификатор US | US-MSTR-02 |
| Заголовок US | Смотреть отзывы клиентов |
| Формулировка | Как мастер, я хочу посмотреть отзывы клиентов, чтобы улучшить качество своих услуг. |
| Роль пользователя | Мастер |
| Польза (ценность) | Понимать оценку своей работы |

| **Тестовый сценарий** | |
| Предусловия | Услуга была оказана |
| Действия (пользователь и система) | 1. Войти в систему под своей учётной записью<br>2. Зайти в раздел «Отзывы»<br>3. Выбрать отзыв |
