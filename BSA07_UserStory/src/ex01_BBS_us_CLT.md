## US #1

| Заголовок | Описание |
|---|---|
| Идентификатор US | US-CLT-01 |
| Заголовок US | Записать на услугу |
| Формулировка | Как клиент, я хочу записаться на услугу онлайн, чтобы сэкономить своё время. |
| Роль пользователя | Клиент |
| Польза (ценность) для роли | Быстро забронировать слот без звонков в салон |
| Требуемые действия | Выбрать услугу, мастера и удобное время |
| **Критерии приёмки** | |
| Предусловие | • Клиент зашёл на сайт<br>• Клиент может быть как авторизован, так и нет |
| Действия пользователя в системе | 1. Выбрать услугу<br>2. Выбрать мастера<br>3. Выбрать дату и время<br>4. Подтвердить бронирование |
| Результат (ценность для пользователя) | Клиент получил уведомление о том, что запись зарегистрирована |

## US #2

| Заголовок | Описание |
|---|---|
| Идентификатор US | US-CLT-02 |
| Заголовок US | Получать напоминание |
| Формулировка | Как клиент, я хочу получать напоминание о предстоящей услуге, чтобы не забывать о записи. |
| Роль пользователя | Клиент |
| Польза (ценность) | Всегда помнить о записи |
| Требуемые действия | Получать напоминание в выбранном канале связи |
| **Тестовый сценарий** | |
| Предусловия | В записи присутствует выбранный клиентом канал связи |
| Действия (пользователь и система) | 1. Система проверяет, есть ли указанный удобный способ связи<br>2. Система проверяет приближение даты записи<br>3. Система отправляет уведомление клиенту за день до записи<br>4. Клиент получает уведомление |
| Ожидаемый результат | • Уведомление пришло за день до записи<br>• Уведомление пришло в выбранном канале связи<br>• Уведомление содержит корректные данные о записи |
