## US #1

| Заголовок | Описание |
|---|---|
| Идентификатор US | US-MGR-01 |
| Заголовок US | Управлять расписанием мастеров |
| Формулировка | Как менеджер, я хочу вносить в систему рабочие дни и часы каждого мастера, чтобы оперативно настраивать их занятость. |
| Роль пользователя | Менеджер |
| Польза (ценность) для роли | Оперативно настраивать занятость мастеров |
| Требуемые действия | Вносить в систему рабочие дни и часы каждого мастера |
| **Критерии приёмки** | |
| Предусловие | • Менеджер авторизован в системе<br>• В системе присутствует список всех мастеров |
| Действия пользователя в системе | 1. Зайти в раздел «Расписание»<br>2. Выбрать мастера<br>3. Выбрать даты и время работы мастера<br>4. Сохранить изменения<br>5. Проверить, что все изменения отображаются в системе |
| Результат (ценность для пользователя) | • Расписание мастеров обновлено в системе<br>• Мастер видит своё расписание<br>• Появились доступные слоты для записи клиентов |


## US #2

| Заголовок | Описание |
|---|---|
| Идентификатор US | US-MGR-02 |
| Заголовок US | Получать отчёты о выполненных услугах |
| Формулировка | Как менеджер, я хочу настраивать фильтры поиска, чтобы получать отчёты о выполненных услугах. |
| Роль пользователя | Менеджер |
| Польза (ценность) | Быстро получать отчёты для анализа |
| Требуемые действия | Выполнять поиск по фильтрам выполненных услуг |
| **Тестовый сценарий** | |
| Предусловия | • В системе присутствуют все записи с услугами, статусами выполнения, клиентами<br>• Менеджер вошёл в систему под своей учётной записью |
| Действия пользователя в система | 1. Зайти в раздел «Отчёты»<br>2. Выбрать необходимые фильтры (дата, мастер, услуга)<br>3. Нажать на «Получить отчёт»<br>4. Система находит необходимые данные, которые сходятся с фильтрами, и создаёт файл с этими данными<br>5. Менеджер загружает файл |
| Ожидаемый результат | • Менеджер получил файл с отчётом в формате `.xlsx`<br>• Все данные в отчёте сходятся с настроенными фильтрами |

## US #4

| Заголовок | Описание |
|---|---|
| Идентификатор US | US-MGR-04 |
| Заголовок US | Добавить мастера |
| Формулировка | Как менеджер, я хочу добавлять новых мастеров, чтобы появилась возможность добавить их в расписание. |
| Роль пользователя | Менеджер |
| Польза (ценность) | Возможность настроить расписание нового мастера |
| Требуемые действия | 1. Открыть раздел «Справочники»<br>2. Выбрать справочник «Мастера»<br>3. Внести данные нового мастера<br>4. Сохранить изменения |
| **Тестовый сценарий** | |
| Предусловия | • Менеджер зашёл в свой личный кабинет<br>• Существует справочник «Мастера» |
| Действия пользователя в система | 1. Перейти во вкладку «Справочники»<br>2. Выбрать справочник «Мастера»<br>3. Нажать кнопку «Добавить мастера»<br>4. Заполнить все обязательные поля (ФИО, Должность, Номер телефона, Стаж работы, оказываемые услуги)<br>5. Сохранить изменения<br>6. Проверить, появился ли новый мастер в справочнике «Мастера»<br>7. Перейти во вкладку «Расписание»<br>8. Проверить, появился ли новый мастер в списках мастеров |
| Ожидаемый результат | Во вкладке «Расписание», в списках мастеров появился новый мастер, все данные мастера корректны |
