| Наименование | Назначение | Ключевые атрибуты |
|:---|:---|:---|
| Клиент | Записывается и получает услугу | ID клиента, ФИО, номер телефона, канал связи, факт регистрации |
| Сотрудники | Оказывают услуги | ID сотрудника, ФИО, номер телефона, должность,стаж работы |
| Услуга | Список услуг, которые предоставляет барбершоп | ID услуги, категория, наименование, цена, состав, время оказания |
| Начисление | Список всех произведенных оплат за услугу | ID начисления, ID клиента, от кого, дата, сумма, |
| Отзыв | Все отзывы клиентов за оказанные услуги | ID отзыва, ID сотрудника, содержание отзыва, дата |
| Запись | Все записи на услуги | ID запсиси, ID услуги, ID мастера, ID отзыва, ID начисления, статус выполнения |
| Расписание | Все слоты, доступные и забронированные | ID слота, ID мастера, дата, время начала, время окончания, статус слота |
